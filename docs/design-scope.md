# 토이 실험의 범위와 설계 의도

## 고정한 입력과 비교 질문

연구자가 확인한 연구 맥락에 따라 **AIVIVE에서 선정한 유전자에 대응하는 3453개 probe 목록을 고정해 사용한 토이 실험**으로 설명합니다. 현재 준비 코드는 final_rat_genes.csv의 PROBEID를 읽고 중복 제거한 순서를 유지하며, 자체적인 저변동·저발현 필터를 추가하지 않습니다. 새 유전자 선정 방법의 성능이 아니라 동일한 발현 입력에서 구조·pathway 표현과 모델 계열에 따른 예측 성능을 비교합니다.

이는 연구자가 밝힌 목록 사용 의도와 확보 코드의 동작에 관한 설명입니다. AIVIVE 상위 목록 생성의 모든 세부 기준을 독립 검증했다는 뜻이나 AIVIVE 모델 전체를 재현했다는 뜻은 아닙니다. 목록 선정의 상세 기준은 선행자료 출처로 남기되 이를 현재 모델 실행 코드의 누락과 혼동하지 않습니다. 테스트 정보가 probe 선정에 사용됐다는 증거는 없으므로 그런 누출이 발생했다고 단정하지 않습니다. 현재 비교는 고정 목록을 사용한 조건에서 해석합니다.

## 설계 의도와 검증 범위

아래 의도는 연구자가 확인한 대화·연구 기록에 근거합니다. 코드에서 확인되는 설정값과 선택 이유에 대한 연구 기록, 최적성 검증은 각각 구분합니다.

| 설정 | 당시 선택한 이유 | 검증 범위 |
| --- | --- | --- |
| 작은 MLP encoder | 첫 미팅에서 입력 정보의 효과를 단순하게 비교 | 최적 architecture 탐색은 하지 않음 |
| 발현·구조·pathway branch 분리 | 각 정보를 별도로 처리한 뒤 결합 | 결합 방식 간 충분한 비교는 하지 않음 |
| Pathway당 node 4개 | 같은 소속 probe 집합에서 여러 가중 조합을 표현하면서 모델 규모를 제한하는 초기 절충값 | 1·2·8개보다 좋은지 검증하지 않음. 특정 논문의 권장 최적값이 아님 |
| 기본 cGAN·epsilon-DDPM 손실 | 별도 후보정·추가 pathway loss 없이 모델 계열 비교 | 각 모델을 충분히 최적화한 비교는 아님 |
| AdamW 학습률 0.001 | AdamW 기본 학습률을 토이 비교의 초기값으로 선택 | 데이터·모델별 최적값인지 검증하지 않음 |
| Dropout 0.1 | 작은 데이터에서 과적합 완화를 의도한 약한 정규화 초기값 | 사용 자체의 효과와 0.1의 적절성을 검증하지 않음 |
| 최대30 epoch 등 공통 설정 | 초기 비교의 조건 고정 | 체계적 하이퍼파라미터 탐색은 하지 않음 |

발현·구조·pathway encoder는 별도 pretraining 없이 각 모델의 목적함수로 함께 end-to-end 학습합니다. MLP는 발현 MSE, DDPM은 noise MSE, cGAN은 적대적 BCE이며 cGAN에 발현 재구성 MSE는 없습니다. MSE의 probe 차원은 동일 가중 평균하고 target이 pair에서 반복되는 횟수에 따른 가중치는 별도로 적용합니다. pathway 소속 위치는 고정하고 연결 가중치는 학습합니다.

## Pathway node 수와 parameter 규모

실제 입력은 gene 자체가 아니라 probe입니다. 한 pathway에 연결된 같은 probe 발현에 서로 다른 학습 가중치를 적용해 unit별 특징을 만듭니다. unit k의 연산은 `SiLU(sum_i x_i*w_ik + b_k)`입니다. 네 unit은 서로 다른 패턴을 표현할 여지를 주지만, 서로 다른 생물학적 기능 네 가지라고 해석하지 않습니다. 학습 후 네 특징이 실제로 서로 다른 정보를 얻었는지도 별도 검증한 것은 아닙니다.

연결 E=19,254개, pathway P=321개, readout32에서 unit 수 U에 따른 pathway branch parameter는 `E*U + P*U + (P*U)*32 = 29,847*U`입니다. 연결별 가중치·pathway별 bias·bias 없는 readout Linear를 포함하며 dropout과 SiLU에는 parameter가 없습니다. 모델 전체 parameter가 아닌 pathway branch만의 수입니다.

| Pathway당 unit | Pathway branch parameter |
| --- | ---: |
| 1 | 29,847 |
| 4 | 119,388 |
| 8 | 238,776 |

**왜 여러 unit을 두는가**는 표현 설계의 이유이고, **왜 하필4개인가**는 검증되지 않은 초기 숫자 선택입니다. 학습률0.001·dropout0.1도 같은 구분을 적용합니다. 같은 설정은 비교 조건을 맞춘 것이며 각 모델을 충분히 튜닝했거나 동등한 최적 성능에 도달했다는 뜻은 아닙니다.

후속 후보로 MLP의 내부 검증에서만 unit 수·학습률·dropout을 하나씩 바꾸는 민감도 분석을 고려할 수 있습니다. 이번에 실행하거나 승인된 분석이 아니며, 테스트 점수로 값을 고르거나 현재 반복 분할 실행기에 몰래 추가하지 않습니다.

## 저변동 probe와 발현 척도

현재 코드에서 지정된 3453개 probe 모두를 입력·예측 대상으로 사용합니다. 반응 크기에 따른 probe 제외나 추가 loss 가중치는 없습니다. 최종 절대·반응 RMSE도 전체 probe를 동일 가중해 계산합니다. 거의 변하지 않는 probe를 잘 맞춘 것과 반응하는 probe를 잘 맞춘 것을 이 전체 지표만으로 분리해 주장하지 않습니다.

source는 학습 고유 source 조건의 probe별 평균·표준편차로 표준화하고, target은 학습 고유 target 조건의 probe별 평균만 빼며 예측 후 복원합니다. 입력의 조건 간 분산과 처리군−대조군 반응 크기는 서로 다른 개념입니다. 표준화는 저변동 필터가 아니며, 코드에 StandardScaler가 있다는 사실이 원시 CSV 이전의 RMA·log2 등 처리를 입증하지도 않습니다.

입력 발현의 상위 정규화 과정과 log2 척도 여부는 확보된 준비 코드만으로 확정하지 않습니다. 확인 전에는 반응을 **입력 발현 척도에서의 treated−control 차이**로 설명하며 log2 fold change라고 단정하지 않습니다. 여기서 raw probe space라는 표현은 target PCA·target 분산 표준화를 하지 않는다는 뜻이지 비정규화 원시 intensity임을 입증하는 표현이 아닙니다.

## 현재 해석과 변경 금지 범위

구현과 설정값은 확인됐고, 설계 의도는 연구 기록으로 설명하며 최적성 검증과 구분합니다. 최종 9조건은 구조를 모두 켠 고정 probe 목록의 비교이며, 실제 KEGG가 MLP의 두 오차와 DDPM의 반응 오차를 낮춘 단일 분할·단일 mask 탐색 결과입니다. 평균 pathway 12조건과 구분합니다.

이번 설명 갱신을 근거로 저변동 필터나 추가 log 변환을 임의로 적용하지 않습니다. 그렇게 바꾸면 기존 실험과 다른 입력을 학습하게 됩니다. 별도 승인·설계 없이 재학습하거나 기존 결과를 대체하지 않습니다. [검증 상태](verification-status.md)와 [실제 코드 해설](code-walkthrough.md)을 함께 참고하세요.
