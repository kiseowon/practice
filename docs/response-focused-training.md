# 조건 평균 반응 예측을 위한 새 프로토콜

기존 최종 코드·결과를 보존하고 `scripts/response_focused_training.py`를 별도로 추가했습니다. 기존 결과의 재현 실행기가 아니라 목표 척도와 선택 지표를 바꾼 새 실험입니다. 실제 연구 데이터 학습은 이 작업에서 실행하지 않았습니다.

## 무엇을 학습하고 평가하는가

목표는 조건 평균 반응 예측 개선입니다. 현재 모델은 여전히 **조건 평균 절대 발현**을 학습하며, 처리군·대조군 예측의 차이로 반응을 계산합니다. 직접 반응을 정답으로 학습하는 모델이나 훈련 평균 반응 잔차 모델을 구현한 것은 아닙니다. 평가 목표와 학습 손실의 이 차이를 남겨 둡니다.

| 계열 | 학습 목적함수 | 예측 |
| --- | --- | --- |
| MLP | target별 pair 중복을 보정한 발현 MSE | 결정적 조건 평균 발현 |
| cGAN | 조건부 적대적 BCE, 재구성 MSE 없음 | 정규 노이즈 16차원으로 생성한 4개 평균 |
| epsilon-DDPM | 추가 노이즈 epsilon의 MSE | 100단계 stochastic 역과정 생성 4개 평균 |

세 계열 모두 기존 발현 encoder, Morgan+presence encoder, pathway branch와 조건 정보를 결합합니다. 구조 입력은 항상 켭니다. pathway 없음 / 실제 sparse / degree 보존 무작위 sparse를 비교합니다. 고정 연결 위치의 가중치는 최종 손실로 학습하며 별도 pathway 정답·사전학습은 없습니다. DDPM은 기존 noisy+correction 예측기를 유지합니다. 생성 분포 품질이나 모델별 최적 튜닝을 입증하는 설계는 아닙니다.

## 전처리와 누수 방지

| 항목 | 처리 | 적합에 쓰는 자료 |
| --- | --- | --- |
| source 발현 | probe별 StandardScaler, 추가 log/RMA 변환 없음 | 고유 학습 source 조건 |
| dose·시간 | dose log1p 후 수치 열 StandardScaler | 학습 pair |
| 단위·용량 등급 | unknown 무시 one-hot | 학습 pair |
| Morgan | binary 그대로, 누락 0 + presence | 저장 입력, scaler 없음 |
| pathway | 기존 projection·probe 순서 검사; sparse는 양수 연결만 사용 | 외부 annotation 고정 |
| target 발현 | probe별 학습 평균 제거 후 **공통 RMS 한 개**로 나눔 | 고유 학습 target 조건 |

공통 RMS는 모든 학습 target·probe의 중심화 값 전체에서 계산합니다. probe마다 분산을 나누지 않아 저변동 probe를 상대적으로 증폭하지 않습니다. 목표와 DDPM 노이즈의 수치 규모를 조정하려는 선택이며 성능 개선 근거는 아직 없습니다. MLP 손실의 공통 배율도 바뀌므로 기존 최적화와 동일하다고 보지 않습니다. 예측에는 공통 RMS와 probe별 평균을 역적용한 뒤 여러 source의 예측을 target별 평균합니다. 전처리 객체에 평균·척도를 저장합니다.

내부 학습 89개에 전처리를 적합하고 검증 23개로 학습률과 epoch를 선택합니다. 이후 112개에 전처리를 다시 적합하고 모델을 초기화해 선택 epoch만큼 재학습합니다. 테스트 28개는 후보 선택에 사용하지 않습니다. 반응 RMSE를 선택 지표로 사용하며 절대 RMSE는 보조 보고입니다. 실제 테스트 대조군은 정답 반응 계산에만 사용하고 예측 반응에는 예측 대조군을 뺍니다.

입력 발현의 RMA/log2 여부는 파일 출처 연결로 확인해야 합니다. 값 범위만으로 확정하지 않습니다. dose 단위의 물리적 환산도 추가하지 않았습니다.

## 하이퍼파라미터의 이유와 검증 범위

| 설정 | 이유 | 검증 범위 |
| --- | --- | --- |
| 학습률 0.0003 / 0.001 | 기존 초기값과 더 작은 값의 제한된 후보 탐색 | 내부 반응 RMSE로만 선택, 전역 최적 아님 |
| 최대 30 epoch, 1·5·10…30 평가 | 기존 예산 유지, 검증으로 학습 길이 선택 | 더 긴 학습의 효과 미검증 |
| dropout 0.1, AdamW decay 0.01 | 기존 약한 정규화 설정 유지 | 각 값의 최적성 미검증 |
| batch 128, gradient norm clip 1 | 기존 메모리·최적화 설정 유지 | 민감도 미검증 |
| pathway당 4개 특징, readout 32 | 평균 하나보다 다양한 패턴을 허용하되 기존 규모 유지 | 생물학적 4기능이라는 뜻 아님, 최적성 미검증 |
| DDPM 100단계, 생성 평균 4개 | 기존 계산 예산 유지 | 샘플 수·스케줄 최적성 미검증 |

MLP는 기본 선택이고 GAN/DDPM은 명시적으로 선택합니다. 같은 후보 수를 준 것이 모델별 충분한 튜닝을 뜻하지 않습니다. 실패한 모델을 보고 테스트에 맞춰 설정을 바꾸면 그 결과도 탐색 결과입니다.

## 실행

저장소 루트에서 다음은 **계획만 출력**하며 입력 읽기·mask 생성·학습을 하지 않습니다. 경로는 서버의 실제 보존 폴더로 지정합니다.

```bash
python scripts/response_focused_training.py \
  --prepared /실제/경로/prepared_controls \
  --structure /실제/경로/morgan_binary.csv \
  --annotation /실제/경로/kegg_snapshot \
  --out /새로운/결과/폴더
```

입력은 prepared_controls의 발현 NPY 2개, 조건 CSV 2개, pairs.csv.gz, probes.csv와 구조 CSV, KEGG projection.npy·pathway_audit.csv·provenance.json입니다. 기존 준비 데이터와 annotation의 경로·형식을 그대로 사용합니다.

실제 실행을 결정하면 같은 명령에 `--execute`를 추가합니다. 기본 5분할 × MLP × 3표현은 15조건, 학습률 후보 fit 30회 + 최종 refit 15회로 최대 45 fit입니다. `--model-seeds 42 43 44`는 45조건·최대135 fit입니다. `--families mlp cgan ddpm`으로 세 계열을 선택할 수 있습니다. 기본 mask는 하나이며 `--graph-seeds 20261102 20261103 20261104`로 늘립니다. 세 계열 실행을 이번 작업에서 수행하지 않았습니다.

출력에는 run.json의 입력·소스 SHA-256과 패키지 버전, 분할·전처리 객체, mask와 감사 기록, 조건별 validation_history.csv·selection.json·model.pt·predictions.npz·metrics.json, 완료 표지, 전체 결과·대응 차이 CSV가 포함됩니다. 같은 폴더 재개 시 family·seed·mask·설정·입력·소스·환경 계약이 같아야 합니다. 완료 표지가 있는 조건만 건너뜁니다.

## 기준선과 해석

용량 등급별 훈련 평균 반응과 변화 없음 기준선을 함께 계산합니다. 훈련 target을 중복 제거하고 화합물별 평균 후 화합물 간 평균을 냅니다. 기준선은 반응만 예측하므로 absolute RMSE를 만들지 않습니다.

**이미 보고된 시간×용량 등급 기준선보다 개선됐는지는 이 실행기 출력만으로 판단할 수 없습니다.** 이 실행기의 기본 기준선은 용량 등급만 구분합니다. 기존 강한 시간×등급 기준선도 같은 분할·같은 target·같은 화합물 집계 정의로 대조해야 하며, 그 코드가 독립적으로 확인되기 전에는 수치만 합쳐 우월성을 주장하지 않습니다.

분할 간 테스트 화합물은 겹치고 기본 모델 seed·mask는 각각 하나입니다. seed42 결과는 설계에 참고한 탐색 결과입니다. 신뢰구간·p-value·구조 추가 효과는 제공하지 않습니다. 모의 테스트는 전처리 누수 방지, 역변환, 반응 지표 선택, 재학습 흐름을 확인하며 실제 학습 재현이나 성능 개선 검증이 아닙니다.
